Sembilan utilitas AI Toolkit yang berjalan lokal, tanpa langganan dan tanpa mengirim data ke cloud: Stem Separator, Music Studio, Voice Synthesis, Fine-tune (ID), Studio Creation (Image + Video), Remover, LLM Hub (GGUF), Screen Coder, dan Media Downloader.

Rilis ini menambah stack Remover beserta Studio Creation, Screen Coder, dan LLM Hub, memindahkan proyek ke ESM, menambahkan vendor fork llama.cpp untuk inferensi GGUF offline, dan menutup beberapa celah keamanan pada API.

## Catatan Penting

Repository ini memakai Git LFS. Checkpoint VITS Kafka (`server/storage/models/kafka/kafka.pth`, 159.650.901 byte) disimpan sebagai objek LFS, jadi **`git lfs install` wajib dijalankan sebelum clone** agar model ikut terunduh:

```bash
git lfs install
git clone https://github.com/KiRaRyuuKi/Waves.git
```

Kalau model belum terunduh, Voice Synthesis dan Fine-tune tidak punya checkpoint dasar. Format `.pth` lain tetap dikecualikan, jadi hanya checkpoint Kafka yang ikut di-commit.

## Highlights

- **Remover** di `server/remover.py` dengan isolasi `REMBG_HOME`/`U2NET_HOME`/`XDG_DATA_HOME` ke `server/storage`, model U2-Net / ISNet / Silueta via `scripts/dl_remover.ps1`, dan UI brush dengan perbandingan before/after.
- **Studio Creation** merupakan alur gabungan Image + Video dengan model Stable Diffusion (diffusers) dan AnimateDiff / Wan 2.1 T2V 1.3B.
- **Screen Coder & LLM Hub** merupakan agent pengodean dari screenshot dan pengelola model GGUF, keduanya memakai `vendor/coder` dan `vendor/llama` (ggml-org/llama.cpp, MIT, fb34fc2) supaya jalan sepenuhnya offline.
- **Hardening Keamanan** merupakan batas upload terpusat di `server/uploads.py` (500 MB audio, 20 MB image, 100 MB per file dataset, 200 file per dataset), validasi path traversal untuk `dataset_id`, `repoId`/`filename`, dan `model_id`, origin guard untuk request yang mengubah state, serta masking API key di endpoint config Coder.
- **Regression Test**, `tests/security_regression.py` dengan 39 pemeriksaan A01-A05.
- **CLI Lokal** menggunakan `npx waves` berjalan tanpa install global lewat `bin/waves.js`.
- **Dokumentasi**, README dengan sembilan utilitas, pohon arsitektur, tabel batas upload dan keamanan, plus galeri 11 screenshot interaktif di `docs/screenshots/index.html`.
